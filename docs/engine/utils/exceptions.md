# Exceptions

*Module*: `terminaltexteffects.utils.exceptions`

Every TTE exception derives from `TerminalTextEffectsError`, so catch it to handle any engine error. The specific
exceptions are importable from `terminaltexteffects.utils.exceptions` and are grouped below by the module that defines
them. Import the base class from `terminaltexteffects.utils.exceptions.base_terminaltexteffects_exception`.

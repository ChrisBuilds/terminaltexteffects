Added filled surfaces to `Space3D`. `Body.draw` draws a body with a look: `Shaded` fills faces with a symbol ramp and gradient by their angle to the light, `Solid` uses one symbol, `Textured` wraps the input text (or any string) over the faces, and `Wireframe` draws the edges. Looks can be set per face. The space draws every body into one depth buffer each frame with characters it creates and manages, so the effect's own characters are never used, and text mounted on a drawn body reads on top of it.

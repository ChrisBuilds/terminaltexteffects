Added an optional interactive interface, installed with `pip install 'terminaltexteffects[tui]'`. It lists every effect, edits each option with an input that fits its type, and previews effects over text you type, paste, or pipe in. It can also open and save text, show the equivalent `tte` command, record `.tterec` files, and keep input colors while editing. Running `tte` with no effect opens it when installed, or with input and no effect; `--tui` opens it explicitly.

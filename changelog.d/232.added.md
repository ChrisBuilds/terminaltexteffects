Added an optional interactive interface, installed with `pip install 'terminaltexteffects[tui]'`. It lists every effect, edits each option with an input that fits its type, and previews effects over text you type, paste, or pipe in. It can also open and save text, show the equivalent `tte` command, record effects as `.tterec`, GIF, or WebP files (GIF and WebP need `agg`), and keep input colors while editing. Running `tte` with no effect opens it when installed, or with input and no effect; `--tui` opens it explicitly. A playback bar pauses, steps, replays, and loops effects, which are prepared on a background thread for a smoother frame rate. The interface can also filter the effect list, replay automatically when options change, pick colors, browse for files, resize the canvas by dragging its outline or fitting it to the text, load a pasted `tte` command, color text and insert block and line symbols from a toolbar, and restore the last session.

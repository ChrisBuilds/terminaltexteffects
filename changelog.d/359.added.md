The 3D API is reachable from the top-level package: `tte.shapes` holds every body shape (`tte.shapes.Sphere(10)`), `tte.looks` the looks `body.draw()` takes (`tte.looks.Shaded()`), and `tte.Vec3`, `tte.Rotation`, `tte.rotation_about` and `tte.Body` sit beside `Coord` and `Color`. `from terminaltexteffects.shapes import Sphere` and `from terminaltexteffects.looks import Shaded` work too.

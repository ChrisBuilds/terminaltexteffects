Added `tte --export FILE` to render an effect once and save its frames, and `tte --play PATH` to replay a recording or a directory of `.tterec` recordings without running the effect, for screensavers and background displays. Playback supports `--repeat`, `--frame-rate`, `--hold`, `--shuffle`, `--alt-screen`, and `--anchor-canvas`, and rejects recordings containing escape sequences other than color. Effects can time phases in seconds with the new `Terminal.clock()`, which Matrix `--rain-time` and Thunderstorm `--storm-time` now use so recorded phases last as long as live ones.
